# Hotel Booking

A beginner-friendly full-stack hotel booking demo built with Python Flask, SQLite, HTML, CSS, and JavaScript.

## Features
- Responsive hotel landing page and room cards
- Booking form with required-field, date, guest-capacity, and availability checks
- SQLite database storage
- Booking confirmation and reference number
- Manage and cancel bookings
- Parameterized SQL queries

## Run locally
1. Install Python 3.10 or newer.
2. Open this folder in VS Code.
3. Create and activate a virtual environment:

   **Windows**
   ```bash
   python -m venv .venv
   .venv\\Scripts\\activate
   ```

4. Install Flask 3.0 ,4.0 
   ```
5. Start the app:
   ```bash
   python app.py
   ```
6. Open http://127.0.0.1:5000 in your browser.

The `hotel.db` database is created automatically when you run `app.py`.
